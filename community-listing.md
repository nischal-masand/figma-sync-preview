## Description (long form for the plugin detail page)

> **Figma's native preview shows one screen at a time. This plugin shows up to four.**
>
> Compare light and dark modes, mobile and desktop layouts, or any combination of frames — side by side, scrolling in perfect sync.
>
> **What it does**
> • Preview up to 4 frames simultaneously in one window
> • Wrap previews in real device frames: iPhone 14 Pro, iPhone 14 Pro Max, iPad Pro 12.9", Desktop, or the frame's actual size
> • Scroll one panel — all the others scroll with it, in real time
> • Toggle the plugin between light and dark themes
> • Resize the plugin window to fit your screen
>
> **Great for**
> • Designing responsive layouts across breakpoints
> • Comparing theme variants (light vs dark)
> • Walking stakeholders through a flow across devices in one view
> • Checking that spacing, type, and components hold up at every screen size
>
> **How to use**
> 1. Select your frames in Figma
> 2. Open the plugin and click to add each one as a panel
> 3. Scroll any panel — the rest follow
>
> Built for #ConfigMakeathon.
